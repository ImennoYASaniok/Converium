## О проекте

### Описание

Converium - большая онлайн платформа для совместной подготовки к экзаменам и выкладывание своих курсов. В ней вы можете отслеживать свой прогресс, использовать встроенные сервисы для удобной подготовки и обмениваться материалом

### Проблема

Подготовка к экзаменам — одиночный и демотивирующий процесс. Сложно отслеживать прогресс, найти качественные материалы и сохранить дисциплину без внешней поддержки.

### Решение

Converium добавляет **социальный элемент** в обучение: пользователи создают курсы, учатся вместе с друзьями, соревнуются в прогрессе и мотивируют друг друга.

### Ключевые фичи

| Фича                       | Описание                                                                                                                                                                                                            |
|----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Пользовательские курсы** | Можно создавать структурированные курсы в виде DAG (антициклического ориентированного графа), где вершины - шаги изучения (теория, тесты, практика), а по рёбрам можно попадать в следующие шаги.                   |
| **Система прав на курс**   | `PUBLIC` (после модерации, все пользователи Converium), `FRIENDS_ONLY` (друзья владельца), `CERTAIN_PEOPLE` (только добавленные) - видимость. `READ` (чтение), `EDIT` (изменение), `ADMIN` (полный доступ) - права. |
| **Совместное обучение**    | Можно приглашать друзей, назначать права доступа (READ/EDIT/ADMIN) и наблюдать за прогрессом других                                                                                                                 |
| **Чаты к курсам**          | Каждый непубличный курс получает свой чат для обсуждения материалов                                                                                                                                                 |
| **Аналитика по курсу**     | Проценты прохождения, система достижений                                                                                                                                                                            |
| **Доски к шагам курса**    | К каждому шагу курса можно создать доску с автоматической синхронизацией действий, в которой можно делать заметки и использовать как 2d редактор                                                                    |


## Roadmap

### Версия 1.0 (MVP)
- [ ] Создание сервисов пользователей (регистрация, вход, профиль, друзья, забанненые пользователи, админы. модерры)
- [ ] Создание сервиса курсов с DAG-структурой (дерево, шаг, прикрепление материала, комментарии к курсу и шагам, права доступа на курс)
- [ ] Редактор тестов для шага курса (создание и прохождение тестов по теме шага курса)
- [ ] Аналитика по каждому курсу (прогресс выполнения курса, тестов и другое)
- [ ] Аналитика по каждому пользователю (прогресс выполнение курсов, популярность открытых курсов и другое)
- [ ] Чат на websocket (в курсе и на шагах курса)
- [ ] Интерактивная доска к каждому шагу с синхронизацией в реальном времени (2d-редактор с базовыми фичами)
- [ ] Чат поддержки на сайте (сообщение админу и модеру. Отдельная вкладка сообщений от пользователей в поддержку у админов и модеров)
- [ ] Отладка мобильной версии сайта

### Версия 1.1
- [ ] ИИ для обобщения информации по конспектам в шаге курса
- [ ] ИИ для составления тестов по теме и файлам, приложенным к шагу курса и по всему курсу 

### Будущие релизы
- Мобильное приложение
- Рекомендательная система курсов на основе интересов


## Технологический стек

- **Backend**: Kotlin (Spring-boot)
- **Frontend**: Vue
- **База данных**: PostgreSQL
- **Контейнеризация**: Docker, docker-compose


## Предварительные требования

- Установленные [Docker](https://docs.docker.com/get-docker/) и [docker-compose](https://docs.docker.com/compose/install/)
- Установленный [Git](https://git-scm.com/downloads)


## Быстрый старт

Клонировать репозиторий
```bash
git clone https://github.com/ImennoYASaniok/Converium.git
cd converium
```

Запуск backend (включая бд)
```bash
docker-compose up -d --build
# -d для запуска в фоне, --build для пересборки (или начальной сборки)
```
Сервер доступен на http://localhost:8080/api


## Полезные команды

### Создание и запуск

Принудительное пересоздание контейнеров:
```bash
docker-compose up --force-recreate
```

Запуск только приложения (без зависимостей):
```bash
docker-compose up --no-deps app
```

Запуск только бд:
```bash
docker-compose up -d db
```

### Остановка и удаление контейнеров

Остановка с удалением контейнеров:
```bash
docker-compose down
```

Остановка с удалением контейнеров и томов (volumes):
```bash
docker-compose down -v
```

Остановка с удалением контейнеров, томов (volumes) и контейнеров старых версий:
```bash
docker-compose down -v --remove-orphans
```

Остановка без удаления контейнеров:
```bash
docker-compose stop
```

### Просмотр и отладка

Логи всех сервисов:
```bash
docker-compose logs
```

Логи приложения в реальном времени:
```bash
docker-compose logs -f app
```

Список запущенных контейнеров:
```bash
docker-compose ps
```
